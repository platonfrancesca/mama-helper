# Glossary

**Reminder**: something a parent wants to be reminded about for one child, either once or on repeat.

**Repeat pattern**: how often a reminder comes back: none (once), daily, or weekly on chosen days.

**Occurrence**: one moment a reminder is due. A repeating reminder has many occurrences, but only the **next occurrence** is tracked.

**Notification**: the message the parent receives shortly before an occurrence (10 minutes before). Each occurrence produces at most one notification.

**End date**: optional last day a repeating reminder can occur. If it's empty, the reminder repeats until the parent deletes it.

**Missed occurrence**: an occurrence whose time passed without a notification (for example, while the server was down). It's skipped, not sent late.

**Finished reminder**: a reminder that has been notified and has no next occurrence: a one-time reminder after it fires, or a repeating one past its end date.
